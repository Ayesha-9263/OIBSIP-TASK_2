# 📊 Unemployment Analysis with Python

## 👩‍💻 Author
**Ayesha Ansari**

---

## 📌 Project Overview
This project is based on analyzing unemployment trends in India using Python.  
I performed data cleaning, preprocessing, and visualization to understand how unemployment varies across different states, regions, and over time.

---

## 🎯 Objective
The main objective of this project is to:
- Analyze unemployment rate patterns in India  
- Compare unemployment across states and regions  
- Visualize trends over time  
- Generate meaningful insights from the dataset  

---

## 🛠 Tools & Technologies Used
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  

---

## 📂 Dataset
The dataset used in this project is **"Unemployment in India"**, which contains:
- State-wise data  
- Region-wise data  
- Employment & labour participation details  
- Time-based unemployment records  

---

## ⚙️ Steps Performed

### 🔹 1. Data Loading
- Loaded dataset using Pandas  
- Renamed columns for better readability  

### 🔹 2. Data Cleaning
- Converted Date column into proper datetime format  
- Removed missing values  

### 🔹 3. Data Analysis
- Generated statistical summary  
- Identified the state with highest unemployment  

### 🔹 4. Data Visualization
- Region-wise unemployment comparison  
- State-wise unemployment analysis  
- Time series trend of unemployment  
- Correlation heatmap  
- Distribution plot of unemployment rate  

---

## 📈 Key Insights
- Unemployment varies significantly across states  
- Some regions consistently show higher unemployment rates  
- Trends over time show fluctuations in unemployment  
- The dataset reveals important relationships between employment and labour participation  

---

## 📊 Visualizations Included
- Bar Charts (Region & State analysis)  
- Line Plot (Time series trend)  
- Heatmap (Correlation analysis)  
- Histogram (Distribution of unemployment rate)
